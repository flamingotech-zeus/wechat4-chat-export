# 微信 4.x 聊天记录导出

[English](README.md) | [简体中文](README.zh-CN.md)

> 纯 Python 从本机微信 4.x 本地库导出聊天记录为 Markdown，聊天图片一并解密 —— 不装任何第三方逆向工具。

## 这是什么

这不是那种要装魔改版微信客户端的记录查看器，也不是套在某个现成逆向工具外面的壳。它是一份独立实现，直接打开本机微信 4.x 的数据库，把内容写成干净的 Markdown。

它之所以单独做一遍，是因为这个领域里叫得出名字的工具都消失了：PyWxDump 已被 DMCA 下架，chatlog 没有 release，剩下的仓库在国内还常常打不开。所以我们用 Python 加一个加密库，把整条链路重新走了一遍。

## 为什么开源

这是我们公司平时自己在用的东西之一。日常用来归档项目沟通记录、复盘跟合作方谈过什么、以及把自己的一些记录留在自己手里，而不是放在别人的云端。

用了一段时间之后就不再想它了 —— 一般到这个程度，就说明它值得拿出来分享。这里面没有任何客户数据或业务逻辑，就是一个有微信的人都用得上的通用工具。所以我们整理了一下放出来。

## 能做什么

- **SQLCipher 4 数据库解密。** 微信 4.x 的消息存在一个加密的 SQLite 库里，解密路径完整实现。
- **密钥由内存扫描恢复。** 数据库密钥不在配置文件里，要从运行中的进程内存里捞出来，这一步的全过程都写清楚了。
- **V2 图片格式解密。** 聊天图片用的是一种封装格式，要先解出这一层才能得到正常的 JPEG 或 PNG。
- **WAL 环形缓冲合并。** 微信是通过预写日志落盘的。只读主库文件会静默丢掉最新的一批消息。这里把 WAL 正确合并了，消息缺失和错序两个问题一起解决。
- **纯文本导出器。** `export_text.py` 会把图片、表情、视频、语音剔除，输出一份干净好读的对话文本。
- **边界写明白了。** 桌面端能做什么，和未 root 的安卓手机上确实做不到什么，两件事都记录了，后者附官方迁移路径。

## 环境要求

Windows · Python 3.9+ · `cryptography` 包

## 安装

```bash
git clone https://github.com/<你的用户名>/wechat4-chat-export.git
```

然后把整个目录放进技能目录：

| 系统 | 路径 |
|---|---|
| Windows | `C:\Users\<你>\.workbuddy\skills\wechat4-chat-export\` |
| macOS / Linux | `~/.workbuddy/skills/wechat4-chat-export/` |

没有构建步骤，重启对话即生效。

## 怎么用

直接用自然语言提需求就行。触发条件写在 `SKILL.md` 的 `description` 里，命中就会自动加载。

常见的说法：

- "把我和某某的微信聊天记录导出成 md"
- "把我和某某的聊天记录保存下来"
- "导出聊天记录，图片也要解密出来"

它会依次走完：定位数据库 → 恢复密钥 → 解密 → 合并 WAL → 写 Markdown 并解出图片。

## 注意与边界

1. **微信要在运行状态。** 密钥是从进程内存里恢复的，所以客户端得开着、账号得登录着。微信关着或者退出了，什么都拿不到。
2. **微信改版会动结构。** 这份实现是针对微信 4.x 写的。大版本一升，路径和表结构都可能变。真要坏，会坏得很明显，不会悄悄出错。
3. **只有桌面端。** 安卓不 root 的话，数据库在应用沙箱外面读不到。这是系统层面的边界，不是功能没做，仓库里写了这种情况下该走哪条路。
4. **这是个人归档工具。** 未经对方同意导出别人的私人对话，不在我们支持的用法里。
